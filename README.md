# MonGreffier

MonGreffier est un assistant de rédaction et de relecture de jugements pour les juges consulaires.
Il vérifie les sources citées sur Légifrance (textes) et Judilibre (Cour de cassation).
Le juge reste seul décisionnaire.

## Connexion

Dans Claude : Vos plugins, MonGreffier, onglet Connecteurs, bouton Connecter, puis saisissez
votre adresse mail et le code reçu par mail. La connexion se fait par compte (OAuth) ;
aucune clé n'est à saisir ni à installer.
