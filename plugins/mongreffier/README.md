# MonGreffier

Assistant de rédaction et de relecture de jugements pour les juges consulaires.

## Ce que fait le plugin
- Aide à rédiger un jugement à partir des conclusions, ou à relire un projet existant.
- Vérifie les sources citées : Légifrance pour les textes, Judilibre pour la jurisprudence de la Cour de cassation.

## Qui peut l'utiliser
Le plugin est public et gratuit, mais il ne fonctionne que pour les juges inscrits par EvidencAI. Chaque juge se connecte une fois depuis Claude (Vos plugins, MonGreffier, onglet Connecteurs, bouton Connecter), avec son adresse mail et un code reçu par mail.

## Vos données
Le dossier reste dans votre espace Claude, sous votre responsabilité. Les conclusions et les noms des parties ne sont ni enregistrés ni conservés par MonGreffier ; seules les références vérifiées (article, numéro de pourvoi) sont mémorisées vingt-quatre heures, sans lien avec le juge.

## Ce qu'il ne fait pas
- Il ne lit jamais les annexes.
- Le juge reste seul décisionnaire : MonGreffier propose, vous décidez.
